For Lab 3, we learned about CCS which helps display the content on webpages. CSS includes font/background color, font-family, font size, border, padding, and margin.

Welcome To Layout on Web Pages!

On every web page there is always a layout that must be followed. Because it organizes the web page and makes it visible for any device used by the user. This conducted by using the components ofof media query, fluid layout, and flexible image/videos.


Responsive Web Design Comopents

Media Query:

- applies differebt styles on a webpage based on the device

Fluid Layout:

- different types of layout that fills the users screen:

  • Flex Box: layout in arrangment of rows or columns
  • Grid: layout in arrangment of rows and columns

Flexible Image/Video:

- shrinks and grows images to fit any screen
