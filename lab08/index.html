Visual Media Lab


This lab demostrates different types of web images, such as GIF, JPG, and PNG. Each types have different function:

- PNG is a common format for photographs and allows lossless data compression
- GIF provides animation, and is best used for meme and graphic
- JPG is the most common format for photographs
